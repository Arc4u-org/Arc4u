# Arc4u.NServiceBus.RabbitMQ

This library is a wrapper around the NServiceBus library to use RabbitMQ as the transport.

Will be removed and is replaced by [Dapr](https://dapr.io).

This package is deprecated or not shipped in Arc4u 9. See the [package support matrix](https://arc4u-org.github.io/Arc4u/guides/package-support.html) for its status and the replacement.
