# How to build the docs

The site is built with [DocFX](https://dotnet.github.io/docfx/), pinned as a
local dotnet tool in `.config/dotnet-tools.json`. The .NET SDK required by
`src/global.json` must be installed, because the API reference is generated from
the projects in `src/`.

Preview locally (builds the site and serves it on http://localhost:8080):

```bash
cd docs
dotnet tool restore
dotnet docfx docfx.json --serve
```

Check the build the way CI does (any warning fails the build):

```bash
cd docs
dotnet docfx docfx.json --warningsAsErrors
```

Notes:

- `api/*.yml` is generated by `docfx metadata` and git-ignored; only `api/index.md` is hand-written.
- `_site/` and `obj/` are build output and git-ignored.
- The site is published to https://arc4u-org.github.io/Arc4u/.
