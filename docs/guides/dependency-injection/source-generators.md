# Source generator reference

`Arc4u.Dependency.Tool` contains two incremental source generators. This page describes exactly
what each one reads and emits. For the everyday setup, see
[Dependency injection](index.md); for the architecture behind it, see the
[design principles](../../concepts/design-principles.md).

| Generator | Reads | Emits | Method |
|---|---|---|---|
| `DependencyToolGenerator` | The classes of the project marked `[Export]` | `Dependencies.g.cs` | `Register<Name>Types` |
| `GenerateRegisteredTypes` | `Configs/appsettings.json` (additional file) | `GeneratedTypes.g.cs` | `RegisterTypes` |
| `GenerateRegisteredTypes` | `wwwroot/appsettings.json` (additional file) | `GeneratedWwwRootTypes.g.cs` | `RegisterWwwTypes` |

Every method is a `public static void` extension method on `IServiceCollection`, declared in
`public static partial class RegisterExtensions` in the `Arc4u.Dependency` namespace. Add
`using Arc4u.Dependency;` to call it. The methods call `Add...`, never `TryAdd...`: calling a method
twice registers its services twice. Each file starts with `// <auto-generated/>`, so the analyzers
of your project skip it.

## Configuration

The generators have no MSBuild options. `DependencyToolGenerator` needs no configuration.
`GenerateRegisteredTypes` needs the settings file declared as an additional file:

```xml
<ItemGroup>
  <AdditionalFiles Include="Configs/appsettings.json" />
  <AdditionalFiles Include="wwwroot/appsettings.json" />
</ItemGroup>
```

To keep the generated files on disk, set `EmitCompilerGeneratedFiles` to `true`. They are then
written to:

```text
obj/<Configuration>/<TargetFramework>/generated/Arc4u.Dependency.Tool/
  Arc4u.Dependency.Tool.DependencyToolGenerator/Dependencies.g.cs
  Arc4u.Dependency.Tool.GenerateRegisteredTypes/GeneratedTypes.g.cs
  Arc4u.Dependency.Tool.GenerateRegisteredTypes/GeneratedWwwRootTypes.g.cs
```

## DependencyToolGenerator

### Method name

The method is named `Register<Name>Types`, where `<Name>` is the last dot-separated segment of the
assembly name. Characters that are not letters, digits or `_` are removed, and `_` is added in
front of a name that starts with a digit.

| Assembly name | Method |
|---|---|
| `Contoso.Api` | `RegisterApiTypes` |
| `Contoso.Billing.Business` | `RegisterBusinessTypes` |
| `Contoso.Worker` | `RegisterWorkerTypes` |

The method is generated even when the project has no `[Export]` class; it is then empty.

### What is registered

The generator visits every class declared in the project, public or not, including nested classes.
For each class with an `[Export]` attribute it writes one registration. The lifetime is
`Scoped` when the class has `[Scoped]`, otherwise `Singleton` when it has `[Shared]`, otherwise
`Transient`.

| `[Export]` arguments | Generated call |
|---|---|
| none | `services.Add{Lifetime}<TClass>()` |
| `typeof(IService)` | `services.Add{Lifetime}<IService, TClass>()` |
| `"key"` | `services.AddKeyed{Lifetime}<TClass>("key")` |
| `"key", typeof(IService)` | `services.AddKeyed{Lifetime}<IService, TClass>("key")` |

For example, this project `Contoso.Billing.Business`:

```csharp
using Arc4u.Dependency.Attribute;

namespace Contoso.Billing.Business;

public interface IPaymentGateway
{
    string Name { get; }
}

public interface IRepository<T>
{
}

[Export("Stripe", typeof(IPaymentGateway)), Shared]
public class StripeGateway : IPaymentGateway
{
    public string Name => "Stripe";
}

[Export(typeof(IRepository<string>))]
public class StringRepository : IRepository<string>
{
}

[Export, Scoped]
public class InvoiceNumberGenerator
{
}
```

produces this `Dependencies.g.cs`:

```csharp
// <auto-generated/>
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.DependencyInjection.Extensions;

namespace Arc4u.Dependency;

public static partial class RegisterExtensions
{
    public static void RegisterBusinessTypes(this IServiceCollection services)
    {
        services.AddKeyedSingleton<Contoso.Billing.Business.IPaymentGateway, global::Contoso.Billing.Business.StripeGateway>("Stripe");
        services.AddTransient<Contoso.Billing.Business.IRepository<string>, global::Contoso.Billing.Business.StringRepository>();
        services.AddScoped<global::Contoso.Billing.Business.InvoiceNumberGenerator>();
    }
}
```

### Limits

> [!WARNING]
> Known issues on `develop/9.0.0`:
>
> - The attribute is detected by its exact spelling `Export`. `[ExportAttribute(...)]` and
>   `[Arc4u.Dependency.Attribute.Export(...)]` are ignored without a warning.
> - Only the first `[Export]` of a class is used, although the attribute allows several.
> - An open generic class (`[Export(typeof(IRepository<>))]` on `Repository<T>`) produces code that
>   does not compile. Register open generics with `services.Add...(typeof(...), typeof(...))`.

## GenerateRegisteredTypes

### Which file is read

The generator reads an additional file whose path, relative to the project, is exactly
`Configs/appsettings.json` or `wwwroot/appsettings.json` (case-insensitive). The generator takes as
project folder the shortest folder path that contains a `.cs` file of the compilation, so keep at
least one source file, such as `Program.cs`, directly in the project folder. Other files named
`appsettings.json` are ignored, even when declared as additional files.

The file is parsed with `System.Text.Json` defaults: no comments, no trailing commas,
case-sensitive property names. If parsing fails, the build shows warning `CS8785` and no method is
generated. If the file has no `Application.Dependency` section, the method is generated empty.

### Entry format

```json
{
  "Application.Dependency": {
    "RegisterTypes": [
      "Arc4u.Caching.Memory.MemoryCache, Arc4u.Caching.Memory"
    ]
  }
}
```

Each entry of `RegisterTypes` is a string `Namespace.Type, AssemblyName`:

- `AssemblyName` is matched against the files the project references: the first reference whose
  path ends with `AssemblyName.dll` is used. Package references and project references both work.
- Do not add `Version=`. When a version is present, the reference path must also contain that
  version string, which NuGet folders such as `9.0.0-preview37` never do.
- The assembly is read as metadata, without being loaded. The type must be public, since the
  generated code references it.
- The registration follows the `[Export]`, `[Shared]` and `[Scoped]` attributes of the type, with
  the same table as `DependencyToolGenerator`, except that a type with both `[Shared]` and `[Scoped]`
  is registered as a singleton here.
- An entry whose assembly or type is not found, or whose type has no `[Export]`, is skipped without
  a warning.

The generated method groups the registrations by assembly:

```csharp
public static void RegisterTypes(this IServiceCollection services)
{
    // Types registered by nuget package: Arc4u.Caching.Memory
    services.AddKeyedTransient<Arc4u.Caching.ICache, Arc4u.Caching.Memory.MemoryCache>("Memory");
}
```

The 8.x keys `Assemblies` and `RejectedTypes` are ignored.
